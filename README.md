# AI Agent Behavior Code vs Parameters

This example demonstrates why traditional code diffs are insufficient for understanding changes in AI agents. It contrasts a deterministic function, where code changes lead to predictable outcomes, with a simple AI-like agent that exhibits stochastic behavior and dependency on external parameters. The example shows how small code changes or changes in 'hyperparameters' (not visible in code diffs) can lead to complex, non-obvious shifts in the AI agent's overall behavior.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
